# Folder Structure

## `src/app/`
Routing utama Next.js App Router. Setiap folder di sini adalah route.

## `src/components/`
Reusable UI components (Button, Input, Card, dll).

## `src/lib/`
Konfigurasi dan utility libraries (axios instance, prisma client, dll).

## `src/hooks/`
Custom React hooks untuk logic reusable.

## `src/services/`
API calls dan external service integrations.

## `src/types/`
TypeScript interfaces dan type definitions.

## `src/utils/`
Helper functions dan utilities.
